# 加密貨幣多幣現貨策略：品質選幣 + 各幣趨勢開關

> 狀態：研究完成，已完成驗證（見 `docs/validation.md`）；尚未實盤。
>
> **驗證重點：** 回測數字偏樂觀，週日調倉是運氣。實盤建議改為「資金 7 份、每天輪流調倉」
> （回測：年化 61%、最大回撤 -28%、Calmar 2.19）；合理預期為年化 30%～60%、最大回撤約 -45%。
> 回測期間：2018-06 ～ 2026-10-14（日線，週頻調倉、日頻出場）。
> 研究工具：`tools/factor_research.py`；資料下載：`tools/download_binance.py`。

---

## 1. 一句話說明

在幣安 USDT 現貨前 100 大裡，挑「穩定、流動性好、正在創高、且跑贏 BTC」的幣，最多持有 5 檔；
挑不滿就補 BTC，BTC 也不行就放 USDT 活期；持有中的幣跌破均線就每日出場；
最後依策略本身的近期波動，把總部位縮放到年化 40% 波動以內。

全部在**幣安現貨帳戶**內完成，不需要合約、不放空、不加槓桿。

## 2. 完整規則

### 2.1 幣池（每週日）

| 條件 | 設定 |
|---|---|
| 市場 | 幣安 USDT 現貨交易對 |
| 流動性 | 過去 30 天平均成交額（USDT）前 **100** 名 |
| 上市時間 | 至少 **120** 天 |
| 排除 | 穩定幣、法幣幣、代幣化股票、槓桿代幣（日波動長期 < 1% 者自動排除） |

### 2.2 品質分數（選幣排序）

```
品質分數 = 0.5 × 低波動百分位 + 0.5 × 流動性百分位
  低波動 = −(過去 30 天日報酬標準差)
  流動性 = log(過去 30 天平均成交額)
百分位 = 在當週幣池內的排名百分位（0～1）
```

### 2.3 進場（每週日收盤後）

只在**品質分數前 20 名**之中，依分數由高到低，挑出**同時符合**以下兩個條件的幣，最多 **5** 檔，每檔 **20%**：

1. **自身趨勢**：收盤價 ≥ 60 日最高收盤價 × 0.9（距 60 日高點 10% 以內）
2. **相對強度**（BTC 以外的幣）：幣價 ÷ BTC 價格 ≥ 該比值的 30 日均線

> 為什麼限定前 20 名：平均只有 2～3 檔符合條件。若放寬到前 100 名，空格會被「正在被炒作」的低品質幣填滿，
> 回撤從約 -42% 惡化到 -74%（舊版設定下測得）。

### 2.4 補位（每週日）

符合條件的幣不足 5 檔時：

- 若 **BTC 本身**也符合「收盤價 ≥ 60 日高點 × 0.9」，空出的格子全部改買 **BTC**（BTC 可超過 20%）。
- 否則空格放 **USDT**。

### 2.5 出場（每天收盤後）

| 持有狀態 | 出場條件 |
|---|---|
| 新倉（連續持有未滿 2 週） | 收盤價 < **20 日均線** → 當天收盤賣出 |
| 舊倉（連續持有滿 2 週） | 收盤價 < **40 日均線** → 當天收盤賣出 |

賣出後該格放 USDT 至下個週日；週中不補新倉。

### 2.6 整體部位縮放：波動目標（每週日）

```
實際波動 = 策略淨值過去 14 天日報酬標準差 × √365
縮放比例 = min(1, 40% ÷ 實際波動)
各持倉實際金額 = 2.3～2.4 節算出的目標權重 × 縮放比例
```

不加槓桿（比例上限 100%）。縮下來的部分放 USDT。

### 2.7 閒置資金

所有 USDT（未持倉、停損賣出、波動縮放減下來的部分）放幣安**活期理財**（Simple Earn Flexible）。
回測假設年化 2%（無歷史利率資料，為假設值）。

## 3. 參數一覽與回測指令

| 參數 | 值 | `factor_research.py` 參數 |
|---|---|---|
| 幣池大小 | 100 | `--top-n 100` |
| 最多持有 | 5 檔 | `--k 5` |
| 品質因子 | 低波動 30 日、流動性 30 日，各 0.5 | `--combo "lowvol_30:0.5,liq_30:0.5"` |
| 候選範圍 | 品質前 20 名 | `--trend-mode fill --pool 20` |
| 進場趨勢 | 60 日高點 90% 以內 | `--trend donch60` |
| 相對強度 | 對 BTC 比值 > 30 日均線 | `--rel-btc 30` |
| 補位 | BTC | `--fallback BTC` |
| 新倉出場 | 20 日均線，前 2 週 | `--exit-ma-new 20 --new-weeks 2` |
| 舊倉出場 | 40 日均線 | `--exit-ma 40` |
| 大盤濾網 | 不使用 | `--regime none` |
| 波動目標 | 40%，回看 14 天 | `--vol-target 0.4 --vol-lookback 14` |
| 閒置收益 | 年化 2%（假設） | `--idle-rate 0.02` |
| 手續費 + 滑價 | 單邊 0.1% | `--fee 0.001`（預設） |

```bash
python tools/factor_research.py --data <資料夾或zip> --top-n 100 --k 5 --regime none \
  --trend donch60 --trend-mode fill --pool 20 \
  --exit-ma 40 --exit-ma-new 20 --new-weeks 2 --rel-btc 30 --fallback BTC \
  --idle-rate 0.02 --vol-target 0.4 --vol-lookback 14 \
  --combo "lowvol_30:0.5,liq_30:0.5" --start 2018-06-01
```

資料：`tools/download_binance.py` 下載幣安全部 USDT 現貨日 K（含已下市幣），
`tools/repack_for_upload.py` 可重新打包成 < 24MB 的 zip。

## 5. 已知弱點

1. **單一資產帶頭的慢牛會落後 BTC。** 2023、2024 年策略 +76% / +33%，BTC +156% / +121%。
   原因是平均只有一半資金在場，且分散在多個幣。要貼近 BTC 就必須放棄空手機制。
2. **長時間區間震盪會被反覆洗出場。** 全程用 40 日均線出場時，最大回撤 -38% 發生在 2024 年 3～10 月
   BTC 區間震盪期間，由 6 次「買在區間上緣、停損在中下緣」累積而成；加入「新倉前 2 週用 20 日均線」後，
   同一段降至約 -29%，但這類行情仍是策略最主要的回撤來源。
3. **45 日進場通道的回撤明顯較大（約 -40%），波動目標也壓不下來。** 60、75 日通道沒有這個問題，
   但代表進場參數有一定敏感度，驗證時建議特別確認。
4. **大牛市的報酬被波動目標壓縮。** 2021 年 +297%，不含波動目標為 +602%。
5. **熊市無法賺錢，只能少虧。** 歷次熊市中前 100 大上漲的幣只有 0～4%，且事前無法辨識；本策略靠空手防守。

## 6. 回測假設與限制

- **成交價**：以日線收盤價成交，未模擬盤中價格與流動性衝擊；手續費與滑價合計單邊 0.1%。
- **波動目標**為近似做法：每週依縮放比例調整整體報酬，縮放比例的變動另計手續費。
- **活期利率 2% 為假設值**，實際利率浮動且無公開歷史資料。
- **資料**：幣安官方公開資料（data.binance.vision），共 685 個幣（含 194 個已下市）。
  已處理：代號被沿用（中斷 > 7 天拆成兩個資產，如 LUNA）、改面額（QUICK、SUN、BNX、DREP）、
  穩定幣與代幣化股票排除。
- **過度擬合風險**：所有規則與參數都在同一段歷史資料上反覆測試決定（依使用者要求未做樣本外切分），
  實際表現可能低於回測。已盡量選擇「參數附近都穩定」的設定，而非單點最佳值。
- **2018 年 6 月以前**幣安 USDT 交易對太少，未納入。

## 7. 研究過程中測過但放棄的做法

| 做法 | 結果 | 放棄原因 |
|---|---|---|
| 主動買占比（taker buy ratio）選幣 | 10 幣時有效，685 幣時 IC ≈ 0.015 | 原本效果主要來自 BNB 的結構性偏高 |
| 動能選幣（7～180 日） | 前 50 大中 IC 為負 | 幣圈中短期是反轉，不是動能 |
| 量價避雷因子加入排序 | 選出的前 5 名反而變差 | 這些因子擅長找輸家，不擅長找贏家 |
| BTC 大盤濾網 | 不如各幣自身趨勢開關 | 兩者疊加會錯過太多行情 |
| 先篩趨勢、再挑品質（全 100 名） | 回撤 -74% ～ -80% | 會追到正在被炒作的低品質幣 |
| ADX 濾網 | 報酬大減、回撤只少幾 % | 60 日高點條件已涵蓋趨勢強度 |
| ATR 吊燈停損 | 全面劣於均線出場 | 崩盤時 ATR 擴大，停損反而變遠 |
| 停損後冷卻期 | 1～8 週全部變差 | 每次假突破的主角都不同 |
| 熊市限制新進場 | 回撤反而變大 | 強勢幣通常比 BTC 更早轉多 |
| 下行波動取代低波動 | 報酬高但集中在 2021 | 熊市與盤整年較差 |
| 放空（熊市才做，多種排序） | 空方部位回撤 -60% ～ -90% | 假熊市訊號與熊市反彈 |
| 資金費率套利（空手時） | 收益 ≈ 成本 | 策略空手時費率正好最低 |
| 最多 10～20 檔、單幣 ≤ 20% | 加波動目標後劣於 5 檔 | 多出的報酬只來自 2021 山寨季 |
| 回撤達門檻就減半 | 全部變差 | 減碼時通常已跌完 |
| 個別幣依波動縮放 | 報酬砍太多 | 不如整體波動目標 |

## 8. 實盤執行流程（規劃）

全部使用幣安現貨 API；API key 只開「讀取」與「現貨交易」，**不開提幣**，並綁定 IP 白名單。
執行環境需位於幣安可連線的地區（例如台灣本機或東京 / 新加坡 VPS），美國主機（含 Colab）不適用。

**每天 UTC 00:00 後（台灣 08:00，日 K 收盤）**
1. 抓所有 USDT 現貨最近約 200 天日 K。
2. 依 2.5 節檢查持倉，觸發者市價賣出，所得 USDT 申購活期。

**每週日（同一時間，接在每日流程之後）**
1. 依 2.1～2.4 節算出目標持倉與權重。
2. 依 2.6 節算出縮放比例，得到各幣目標金額。
3. 先賣出（不在目標中或需減碼者），再從活期贖回所需 USDT，確認到帳後買進。
4. 剩餘 USDT 申購活期。

**注意事項**
- 單筆最低約 5 USDT，資金過小時每格金額可能不足。
- 下單前檢查交易對狀態（非 `TRADING` 者不買，持有中則優先賣出），處理下市公告。
- 建議先以「模擬模式」（只印訂單不下單）運行數週，確認與回測邏輯一致，再小額上線。
